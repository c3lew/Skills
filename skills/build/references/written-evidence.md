# 書面證據紀律

有些散文本身就是證據 — 凍結例外清單的理由、驗收報告裡的量測宣稱、研究文件的結論。
這種句子的判準只有一條:**第二個人拿字面重新推導,推得出同一個結果。**
build 寫理由、qa 驗理由,兩邊都引用本檔。

## 不准用無界全稱詞

理由句不准出現 `all`、`every`、`everything`、`any`、`no … ever`、`exactly`、
`identical`、`never` 這種沒有邊界的斷言。改寫成數得出來的形式:**母體多少、命中多少、
不一樣的那個是誰**。

- ❌ `identical on all three counts a rule can see`
- ✅ `33 列裡 7 列符合,其中 6 列在規則讀的三個 count 上一致,而那 6 列的窗分別有 142 與 143 筆`

判準不是「這句話對不對」,是「下一個人換一種量法重推,會不會撈到反例」。無界斷言的
反例空間是無限的,所以它遲早被自己的證據檔打掉;換成可數的寫法,反例空間就縮到跟
母體一樣大。

## Guard 要蓋整個主張,不是只蓋數字

守一句話的 readback regex,起點要涵蓋**主張的第一個字**,不是句子裡第一個數字。
數字之前那半句(承載斷言的那半)落在門外的話,把它整句換成更赤裸的講法照樣全綠 —
數字有 guard、措辭沒有,等於沒守。

Mutation 要驗兩種,兩種都得咬:

1. **改壞** — 把值改掉,guard 要紅。
2. **繞過** — 把主張換一種講法(更赤裸的絕對詞、大小寫不同、同義改寫),guard 要紅。

只驗第一種的 guard 守的是數字,不是主張。

## Guard 的完工定義

一支 guard 算做完,三條同時成立:

- **住在預設就會跑的地方** — 測試 suite / CI,不是靠人記得跑某支走查 script。
  沒人跑的 guard 等於沒有。
- **兩種 mutation 都咬得到**(見上)。
- **查不到目標時判 fail,不是靜靜略過** — regex 撈不到那一行、key 不存在,一律算
  「第二個人推不出來」,紅。

給人看的證據**不准靜默截斷**。只印前幾筆就要寫明總共幾筆(`[:3]` 要寫成
「30 筆裡的前 3 筆」),否則讀報告的人會把樣本當全部。
